# Planned Windows developer commands (after bootstrap)
- Install dependencies: `pnpm install`
- Start development apps: `pnpm dev`
- Build all workspaces: `pnpm build`
- Run checks: `pnpm lint` and `pnpm typecheck`
- Run tests: `pnpm test`
- Start self-hosted dependencies: `docker compose up -d`
- Stop dependencies: `docker compose down`
- These commands are planned; verify exact scripts in root `package.json` after scaffolding.
