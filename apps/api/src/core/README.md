# Core platform boundaries

Planned platform domains:
- auth: identity, sessions and authentication strategies.
- workspaces: membership, lifecycle, provisioning and database resolution.
- rbac: roles, permissions, policy guards and authorization context.
- modules: module catalog, manifest validation, activation and navigation contributions.
- audit: platform and workspace audit events.
- settings: platform and workspace configuration.

These folders define intended ownership boundaries only. Services and persistence are not implemented in this Foundation stage.
