## Implemented

- Added Control Plane Prisma enum `WorkspaceType` with `POS` and `ONLINE`.
- Added nullable `Workspace.type` mapped to the Control DB `workspaces.type` column.
- Added additive migration candidate: `apps/api/prisma/migrations/20261113000100_workspace_type_registry/migration.sql`.
- Workspace creation service rejects missing/invalid types before inserting a Workspace and persists the selected type.
- Workspace list API includes the Workspace type.
- Provisioning refuses a Workspace with a null/unsupported type before creating database resources.
- Workspace picker now requires selecting SyncUp POS or SyncUp Online and displays the type for each Workspace.
- Updated disposable test/bootstrap call sites to specify types explicitly.
- Extended workspace bootstrap test to verify the selected type is persisted, invalid/missing type is rejected before creation, and untyped legacy records cannot be provisioned.

## Legacy Compatibility

Existing Workspace rows remain `type = NULL` until a separately reviewed classification/backfill decision. This is intentional and avoids guessing whether an existing Workspace is POS or Online. Existing ACTIVE Workspaces are not modified by this source change. The new provisioning guard applies when provisioning is invoked; it will reject an untyped legacy Workspace rather than silently assign a type.
