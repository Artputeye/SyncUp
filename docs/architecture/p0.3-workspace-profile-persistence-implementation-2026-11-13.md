# P0.3 — Workspace Registry Profile Persistence & Lifecycle Metadata

- Track: 0 — Platform Separation Foundation

## Implemented

1. Added nullable Control Plane Workspace fields:
   - `provisioning_profile_id`
   - `provisioning_profile_version`
   - `provisioning_started_at`
   - `provisioned_at`
   - `provisioning_error`
2. Added database CHECK constraint requiring Profile ID and Version to be either both NULL or both populated.
3. New Workspace creation resolves its profile from Workspace Type and persists the exact ID/version in the same Workspace create operation:
   - POS → `pos-standard@1.0.0`
   - ONLINE → `online-standard@1.0.0`
4. Added a shared pure Profile catalog/resolver used by the registry and provisioning service.
5. Provisioning validates that persisted Profile ID/version match the Workspace Type before creating Tenant infrastructure.
6. Provisioning now records start time, successful completion time and a bounded/sanitized error message on failure; successful completion clears the error.
7. Workspace list/create responses expose the persisted profile identity and lifecycle metadata.
8. Module compatibility and the profile endpoint now resolve the persisted Profile ID/version. Missing, unknown, stale or Type-mismatched profiles fail closed.
9. Extended disposable module lifecycle tests to apply P0.3 migration and assert persisted Profile version behavior.
10. Added a dedicated localhost-only disposable Control DB migration rehearsal.

## Deliberate Limitations / Next Work

- Existing Workspaces retain NULL Profile ID/version and lifecycle metadata. No implicit backfill or classification is performed.
- Profile definitions remain code-backed; only selected Profile identity/version is persisted.
- Profile upgrades, conversions, retries and automatic default-module installation are not implemented.
- ONLINE profile has no eligible modules until Online domain modules are implemented.
- Persistent Control DB migration remains a separate approval gate. No Tenant DB migration or mutation was performed.
- No persistent Workspace provisioning, deployment, commit or push was performed.
