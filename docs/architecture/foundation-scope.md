# Foundation scope

Included in this bootstrap:
- Monorepo workspace configuration and task runner.
- Next.js web shell.
- NestJS API shell with health endpoint.
- Shared contracts, types, config and utility package boundaries.
- PostgreSQL control-plane development service.
- Architecture and tenancy documentation.

Not implemented yet:
- Authentication/session management.
- Workspace creation/provisioning and per-workspace database connection registry.
- Prisma schemas, migrations and secret encryption.
- RBAC policy engine and guards.
- Module catalog, package installer and module activation.
- Audit event persistence, settings, file storage.
- Business modules.
