## Implemented

1. Workspace Selector consumes persisted Profile ID/version and provisioning lifecycle fields from the existing Workspace API response.
2. Selector cards distinguish SyncUp POS, SyncUp Online and legacy/unclassified Workspace records.
3. Cards display Profile identity/version when available and explicitly show missing Profile metadata for legacy rows.
4. Non-ACTIVE and unclassified Workspace cards cannot be entered from the selector.
5. Selecting a POS Workspace opens the existing `/workspace/[slug]/pos` experience.
6. Selecting an ONLINE Workspace opens a separate `/workspace/[slug]/online` landing page.
7. ONLINE landing validates the Workspace against the authenticated `GET /api/workspaces` membership list, shows its Profile identity/version, and does not expose POS checkout navigation.
8. The legacy Workspace root route forwards typed ACTIVE workspaces to their matching product landing, preserving the existing generic management page for unclassified/non-active legacy records.
9. Both product landing experiences provide a return path to the Workspace selector. The POS shell brand/avatar actions now switch to `/workspaces` instead of routing back to the typed Workspace root.
