## 1. Implemented

### Route-scoped RBAC
- \`RbacGuard\` requires \`params.workspaceId\` for every route protected by \`@RequirePermission\`.
- Header-only Workspace scope is rejected.
- Conflicting or multi-value \`x-workspace-id\` is rejected; a matching optional header is accepted.
- Current Commerce controllers remain protected by Auth, Workspace Module Capability and RBAC guards.

### Tenant Prisma client identity and lifecycle
- \`WorkspaceDatabaseRegistry\` checks active membership on every lookup, including cache hits.
- Cached clients are bound to host, port, database name, runtime username and encrypted credential identity.
- Database mapping or credential changes disconnect and replace stale clients.
- Concurrent first-use requests for one Workspace share one in-flight connection.
- The registry re-reads Control Plane mapping after connection and fails closed if identity changed during connection.
- Eviction and module shutdown disconnect cached clients and await in-flight initialization.

### Media and image-import storage
- Added \`workspace-media-storage.ts\` for shared scoped filesystem operations.
- Media object keys must be under the requested Workspace ID; staging keys must be under \`staging/<workspaceId>/\`.
- Rejects absolute paths, traversal segments, empty path segments, duplicate separators and Windows separators.
- Directory components are checked with \`lstat\`; symbolic links and non-directory components are rejected.
- File reads reject symlink/non-regular-file targets and use \`O_NOFOLLOW\` where the platform supports it.
- Writes use exclusive creation and \`O_NOFOLLOW\` where supported.
- Media and staging cleanup validate Workspace scope and reject symlink targets.
- Media responses use \`Cache-Control: private, no-store, max-age=0\`, \`Pragma: no-cache\`, \`Vary: Cookie, Authorization\`, and \`X-Content-Type-Options: nosniff\`.

### Media ID Workspace scoping
- \`MediaService.getMediaFile\` resolves media metadata only through the Tenant Prisma client returned for the requested Workspace.
- A service-level regression test proves an asset found in Workspace A is not found when the same asset ID is requested through Workspace B's Tenant client.

### Image Import Batch ownership and Tenant routing
- Added \`apps/api/scripts/verify-image-import-workspace-isolation.cjs\` and \`test:image-import-workspace-isolation\`.
- Regression test confirms Batch lookup runs against the Tenant DB for the requested Workspace, not another Workspace's Tenant DB.
- Commit lookup must include \`uploaded_by = userId\`; another uploader receives the same not-found behavior as an unknown Batch.
- A valid own-Workspace Batch can complete and write its audit event without mutating the other Workspace's Tenant DB.
- This is a service-boundary regression test, not yet an authenticated HTTP test; the HTTP acceptance item remains open.

### Cache inventory
- Source search did not identify application-level Nest CacheModule/CacheInterceptor, cache-manager, CACHE_MANAGER or Redis application-cache use.
- No Nginx/Traefik/Caddy/Compose proxy configuration was found in the repository search scope.
- Actual production CDN, load balancer, reverse proxy and browser cache policy cannot be verified from this repository and remains an external deployment acceptance item.
